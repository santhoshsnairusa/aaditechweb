# AADIT Techno Solutions - Corporate Website MVP

This is a modern, responsive, and high-performance corporate website built for AADIT Techno Solutions using Next.js 15, TypeScript, and Tailwind CSS. It features a scalable, data-driven architecture preparing the platform for future CMS integrations (like Zoho Creator & CRM) with minimal rework.

## Project Architecture & Data Flow

The MVP currently uses a **local JSON** file as its primary database. It accesses this data via a Service Abstraction (`LocalProductRepository`). This pattern ensures you won't need to rewrite any UI components when migrating to a cloud CMS or Zoho in Phase 2.

```
Visitor -> Next.js Application -> Product Service (Interface) -> Local JSON (products.json)
```

## Getting Started

First, install dependencies:

```bash
npm install
# or
yarn install
```

Run the development server:

```bash
npm run dev
# or
yarn dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Future Zoho Expansions

The frontend architecture already groups data access appropriately:
- `/src/services/productService.ts`
- `/src/services/enquiryService.ts`

When migrating to **Zoho Creator** or **Zoho CRM**, simply implement a new `ZohoProductRepository` matching the existing interface and swap it in the service exports.

## How to Add or Update a Product

For the current MVP phase, an authorized technical user can add or update products by merely editing a structured data file. **No new pages or code changes are required.**

### Step 1: Add the Product Image
Place the new high-quality product image in the local folder:
`public/images/products/new-product.jpg`

### Step 2: Add Entry to Product Catalogue
Open `src/data/products.json` and append the new product strictly following the established JSON structure:

```json
{
    "id": "product-016",
    "name": "New Embedded Controller",
    "slug": "new-embedded-controller",
    "category": "Embedded Computing",
    "shortDescription": "Compact embedded controller for avionics.",
    "description": "Detailed product description emphasizing engineering value...",
    "image": "/images/products/new-product.jpg",
    "features": [
        "Feature 1",
        "Feature 2"
    ],
    "specifications": [
        {
            "label": "Processor",
            "value": "ARM Cortex"
        }
    ],
    "applications": [
        "Embedded Systems",
        "Industrial Control"
    ],
    "featured": false
}
```

The new product will automatically appear in the Products list (`/products`), under its respective category, and a unique detail page (`/products/new-embedded-controller`) will be dynamically generated by Next.js based on its `slug`.
